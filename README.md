# 考研英语作文批改 Skill

把考研英语作文批改流程整理成 Claude Skill，让每次批改都按同一套标准执行：**找错 → 少改 → 翻译 → 估分 → 共性诊断**。

## 设计原则

- **尽量保留学生原文**：只修错误和明显不通顺处，不把学生作文换成范文；实质修改加粗并说明理由。
- **错误分类清楚**：语法/拼写硬错误、词义搭配与事实错误、“可以但不够自然”三类分开列，不为找错而找错。
- **估分有依据、有区间**：评原稿而不是修改稿，先识别英语一/二、A/B 节，再定档次和档内分；不发明固定扣分公式，不保证真实阅卷分数。
- **照片批改更谨慎**：区分学生字迹、范文、划去的文字和教师批注，看不清的词标“疑似”，不猜词扣分。
- **诊断面向练习**：只把反复出现的问题当作习惯，给出可执行的检查动作。

## 结构

```
kaoyan-essay-grading/
├── SKILL.md                 批改流程（Skill 主文件）
└── references/
    └── scoring.md           题型、分值、词数与分档参考
```

## 使用方法

- **Claude.ai**：把 `kaoyan-essay-grading` 文件夹打包成 zip，在“设置 → 功能 → Skills”中上传。
- **Claude Code**：把文件夹放到 `~/.claude/skills/`（个人）或项目内的 `.claude/skills/`。

之后发送作文文本或手写照片，说“帮我批改这篇考研作文”即可触发。
